# Form Styling Challenge

## Project Description
This project is a Contact Us Form Challenge built using
HTML and CSS.

The aim of this challenge was to create a visually appealing
and user-friendly contact form based on a provided wireframe.

The project focuses on styling HTML form elements, creating
a structured layout, and improving user experience.

## Features
- Navigation bar with logo and links
- Search bar and navigation icons
- Two-column form layout
- Topic dropdown menu
- Message textarea
- First Name, Last Name, and Email fields
- SEND button with hover effects
- Input focus effects
- Form validation and error messages
- Responsive form layout for smaller screens

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- HTML5 Form Validation

## Form Fields

| Field | Input Type |
|-------|------------|
| Topic | Dropdown (Select) |
| Message | Textarea |
| First Name | Text |
| Last Name | Text |
| Email | Email |
| SEND | Submit Button |

## Responsive Breakpoints

| Device | Screen Size |
|--------|-------------|
| Mobile / Tablet | 768px and below |
| Desktop | Above 768px |

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Fill in the contact form fields.
5. Test the form validation.
6. Resize the browser to test responsiveness.

## Notes
- The form uses HTML5 validation.
- CSS provides focus effects and validation styling.
- The SEND button does not send data to a server.
- The responsive layout applies to the contact form.
